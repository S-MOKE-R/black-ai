## ✨ Features

| Feature | Description |
|---------|-------------|
| **Two Modes** | Normal (suggests commands) / Full (executes commands) |
| **Memory** | Stores conversation history and interactions |
| **Settings** | Configure API key, user name, and mode |
| **Terminal** | Built-in terminal for command output |
| **Cross-platform** | Works on Kali, Ubuntu, Mint |
| **Open Source** | Free to use and modify |
