Black is an AI-powered bug bounty assistant that helps you with reconnaissance, vulnerability testing, and reporting. It suggests commands based on your target and can optionally execute them in Full mode.

## Features

- **Two Modes:**
  - **Normal:** Suggests commands (safe for learning).
  - **Full:** Executes commands via terminal (requires confirmation).
- **Memory:** Stores conversation history and interactions.
- **Settings:** Configure your API key, user name, and mode.
- **Terminal:** Built-in terminal for command output.
- **Cross-platform:** Works on Linux (Kali, Ubuntu, Mint).
- **Open Source:** Free to use and modify.
